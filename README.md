# 🤖 AI Mentor — Personalized AI Tutor for Learning AI

> **Learn at your level. Practice with intelligence. Grow with feedback. 🚀**

AI Mentor is an AI-powered personalized tutor designed to help students learn Artificial Intelligence through adaptive learning paths, AI-generated practice, instant feedback, and progress tracking.

Instead of giving every learner the same learning experience, AI Mentor adapts learning based on the learner's **level, progress, and practice performance**.

### 🎯 Hackathon Track

**PS-03 — Personalised AI Tutor for Learning AI**

---

## 🎯 The Problem

Students learning AI often face three challenges:

- 📚 They are unsure where to start.
- 🧩 The same learning content is not suitable for every learner.
- 📊 They need better feedback about what to learn next.

AI Mentor addresses these challenges by creating a personalized learning experience based on the learner's **starting level, learning progress, and practice performance**.

The goal is simple:

> **Give every learner a learning path that matches where they are and helps them move forward.**

---

## ✨ What AI Mentor Can Do

| 🧭 Learn Your Way | 🧠 Practice Smarter | 📈 Know Your Progress |
|---|---|---|
| Choose your **Beginner, Intermediate, or Advanced** starting level. | Get **AI-generated practice** based on your topic and performance. | Track lessons, scores, challenges, and learning levels. |

| 💬 Ask Your Mentor | ⚡ Adapt as You Learn | 🏆 Challenge Yourself |
|---|---|---|
| Ask questions and get **context-aware AI explanations**. | Your practice experience responds to your **learning performance**. | Complete topic challenges and unlock the **next learning level** with strong performance. |

### 🔄 The Learning Loop

**Choose → Learn → Practice → Get Feedback → Adapt → Progress**

AI Mentor turns learning AI from a fixed sequence into a **continuous learning journey**.

## 🛠️ Built With

AI Mentor combines a modern web stack with generative AI to create an interactive learning experience.

| Layer | Technologies |
|---|---|
| 🎨 **Frontend** | React • TypeScript • Vite • Tailwind CSS |
| 🧭 **Navigation** | React Router |
| ⚙️ **Backend** | Node.js • Express.js |
| 🧠 **AI Layer** | Google Gemini API |
| 🔌 **API Communication** | REST APIs |
| 🚀 **Deployment** | Render |
| 💻 **Source Control** | GitHub |

### 🤖 Where AI Comes In

Gemini powers the intelligent parts of the platform, including:

- 🧠 AI-generated practice questions
- 📖 Lesson quick-check questions
- 🏆 Topic challenges
- 💬 AI Mentor conversations
- 📊 Learning feedback
- ⚡ Adaptive learning support

The AI layer works together with the learner's **level and performance data** to provide a more personalized experience.
